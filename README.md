# BabyOps

BabyOps is a mobile-first parenting and baby health companion app focused on helping parents understand baby needs, monitor symptoms, access educational content, and analyze baby cries.

## Mobile App Direction

This repository is dedicated to the BabyOps mobile application and is separate from the portfolio website.

### Main Features
- Onboarding
- Authentication
- Home dashboard
- Baby profile and growth summary
- Baby cry recording and analysis
- Cry result and recommendations
- Symptom-based diagnosis flow
- Diagnosis result
- Education feed and article detail
- Parent profile, baby data, and settings

## Suggested Stack
- React Native
- Expo
- TypeScript
- Expo Router

## Planned Navigation
